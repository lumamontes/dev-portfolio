# Impressão

Código Limpo é uma leitura essencial para qualquer desenvolvedor de software que queira escrever código sustentável e legível. Uncle Bob apresenta princípios práticos e técnicas que transformam código bagunçado em software limpo e profissional.

## Principais Aprendizados

- **Nomes Significativos**: Escolha nomes que revelem a intenção
- **Funções Devem Ser Pequenas**: Mantenha funções focadas em uma única tarefa
- **Comentários Nem Sempre São Bons**: O código deve ser autodocumentado
- **Tratamento de Erros**: Use exceções em vez de códigos de retorno
- **Testes**: Escreva testes primeiro, mantenha-os limpos

## Citações Notáveis

> "Na verdade, a proporção de tempo gasto lendo versus escrevendo é bem superior a 10 para 1. Estamos constantemente lendo código antigo como parte do esforço para escrever código novo."

O livro enfatiza que código é lido mais frequentemente do que é escrito, tornando a legibilidade crucial para manutenção e colaboração em equipe.

## Aplicação Prática

Os princípios deste livro melhoraram diretamente a qualidade do meu código. A ênfase em funções pequenas e focadas e nomes de variáveis significativos tornaram meu código muito mais fácil de debugar e manter.
