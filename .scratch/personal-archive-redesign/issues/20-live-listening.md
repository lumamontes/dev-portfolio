# 20: Live Listening Integration

**What to build:** Show what Luma is currently listening to through a privacy-conscious integration that is optional and resilient when no data is available.

**Blocked by:** 12: Music Entries and Music Blog Migration.

**Status:** ready-for-agent

- [ ] The source, authentication and privacy boundary are explicit.
- [ ] Live listening data is never required for core site behavior.
- [ ] Missing, stale, denied or unavailable data has a graceful fallback.
- [ ] Luma can disable or limit the information displayed publicly.
