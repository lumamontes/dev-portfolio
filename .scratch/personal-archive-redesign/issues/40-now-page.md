**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [ ] Content lives in Markdown (one file per language) with an `updatedAt` date shown on the page, so it's obvious when it goes stale.
- [ ] It reuses the listening-now widget for the "listening" part instead of duplicating it.
- [ ] It's linked from the homepage quick links in both languages.
- [ ] Luma writes the first version of the text (this is why it's `ready-for-human`); an agent can build the page around placeholder copy.
